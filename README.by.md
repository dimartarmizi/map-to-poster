# MapToPoster JS

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML) [![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS) [![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript) [![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/) [![Leaflet](https://img.shields.io/badge/Leaflet-199903?style=for-the-badge&logo=Leaflet&logoColor=white)](https://leafletjs.com/) [![MapLibre](https://img.shields.io/badge/MapLibre-212121?style=for-the-badge&logo=maplibre&logoColor=white)](https://maplibre.org/) [![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)

MapToPoster JS — гэта прафесійнае кліенцкае вэб-прыкладанне, якое дазваляе лёгка ствараць уласныя карты-плакаты. Калі вы хочаце стварыць мінімалістычны постар з выявай горада або яркі геаграфічны сувенір, гэты інструмент дазваляе знайсці любое месца ў свеце і ператварыць яго ў эфектны постар з картай. Вы можаце цалкам наладжваць тэмы, макет і параметры экспарту з высокай дакладнасцю. Праграма арыентавана на атрыманне высакаякасных выяваў, прыдатных для друку вялікага фармату, таму яна добра падыходзіць для стварэння арыгінальнага насценнага дэкору або персаналізаваных падарункаў.

## 🚀 Асноўныя магчымасці

* **Гібрыдная сістэма рэндэрынгу**: дазваляе плаўна пераключацца паміж эфектыўным адлюстраваннем карт з тайлаў (Leaflet) і працэдурнай вектарнай графікай (MapLibre GL).
* **Дакладнае геакадаванне**: імгненны пошук месцаў па ўсім свеце з дапамогай API Nominatim.
* **Дынамічныя маркеры**: можна дадаваць, перамяшчаць і наладжваць некалькі маркераў месцазнаходжання, выбіраючы розныя значкі і іх памер.
* **Уласныя маршруты падарожжаў**: дазваляе візуалізаваць падарожжы або пэўныя маршруты з дапамогай убудаванай пракладкі маршрутаў і дынамічнай загрузкі шляхоў.
* **Рамка з паспарту**: можна дадаць класічны эфект галерэйнага афармлення з наладжвальнай шырынёй, таўшчынёй аблямоўкі і празрыстасцю.
* **Элегантная тыпаграфіка**: падабраная калекцыя прэміяльных шрыфтоў з поўнай падтрымкай уласнага тэксту і ручнога задання каардынат.
* **Перамяшчальны UI-слой**: гнуткі слой з назвай горада, які аўтаматычна абмяжоўвае становішча элемента і захоўвае сіметрычны бяспечны водступ ад краёў.
* **Эфекты па краях фону**: паляпшае чытальнасць з дапамогай мяккага віньетавання або лёгкай празрыстасці па краях.
* **Гнуткі макет**: можна незалежна ўключаць і выключаць назвы краін, геаграфічныя каардынаты і подпісы на карце.
* **Прафесійны экспарт**: дазваляе ствараць PNG-файлы высокай якасці з зададзеным дазволам, у тым ліку звышвысокага дазволу — да 50 000 пікселяў.
* **Прыватнасць і прадукцыйнасць**: налады захоўваюцца праз LocalStorage, а ўвесь рэндэрынг адбываецца на баку кліента — вашы даныя ніколі не пакідаюць браўзер.

## 🎨 Тэмы

MapToPoster JS прапануе два розныя спосабы афармлення карт.

### Стандартныя тэмы (Leaflet)

Заснаваныя на якасных растравых тайлах ад вядомых пастаўшчыкоў:

* **Minimal White**: чысты і сучасны стыль (CartoDB Positron).
* **Midnight Dark**: стыльны цёмны рэжым (CartoDB Dark Matter).
* **Classic Street**: стандартнае картаграфічнае афармленне OpenStreetMap.
* **Modern Voyager**: маляўнічы і дэталізаваны стыль (CartoDB Voyager).
* **Satellite View**: высакаякасныя спадарожнікавыя здымкі (Esri World Imagery).

### Мастацкія тэмы (MapLibre GL)

Створаныя ўручную вектарныя стылі з працэдурна падабранымі колерамі:

* **Arctic Frost**: светла-блакітныя адценні і чысты белы колер.
* **Aurora Glow**: пералівістыя зялёныя і ружовыя адценні.
* **Cyber Glitch**: неонавыя акцэнты для лічбавага выгляду.
* **Paper Heritage**: вінтажныя сепія-адценні і дарогі, намаляваныя чарнілам.
* **Volcanic Ash**: глыбокі вугальны фон з яркімі акцэнтамі, падобнымі да вуголля.
* **Blueprint Classic**: тэхнічны стыль цыянатыпіі з архітэктурным выглядам.
* ...і шмат іншых унікальных тэм, такіх як Retro Synth, Charcoal Sketch і Sakura Bloom.

### Налада тэм

Вы можаце лёгка дадаваць уласныя мастацкія тэмы, рэдагуючы файл [src/core/artistic-themes.js](src/core/artistic-themes.js):

1. Адкрыйце `artistic-themes.js`.
2. Дадайце новы аб'ект у экспарт `artisticThemes`:

```javascript
your_theme_key: {
    name: "Your Theme Name",
    description: "Brief description of the style",
    bg: "#HEXCODE",
    text: "#HEXCODE",
    water: "#HEXCODE",
    parks: "#HEXCODE",
    road_motorway: "#HEXCODE",
    road_primary: "#HEXCODE",
    road_secondary: "#HEXCODE",
    road_default: "#HEXCODE"
}
```

Прыкладанне аўтаматычна падхопіць новую тэму і пакажа яе ў меню выбару.

## 🛠️ Тэхналагічны стэк

* **Фрэймворк**: Vanilla JavaScript (ES Modules)
* **Зборшчык**: [Vite 5](https://vitejs.dev/)
* **Картаграфія**: [Leaflet](https://leafletjs.com/) (растравыя карты) і [MapLibre GL](https://maplibre.org/) (вектарныя карты)
* **Стылі**: [Tailwind CSS 3](https://tailwindcss.com/)
* **Рэндэрынг**: [html2canvas](https://html2canvas.hertzen.com/)
* **Тыпаграфіка**: Google Fonts, у тым ліку Outfit, Playfair Display і Cormorant Garamond
* **API**: Nominatim (пошук) і OSRM (маршруты)

## 📦 Пачатак працы

Выканайце наступныя крокі, каб атрымаць лакальную копію праекта і запусціць яе.

### Патрабаванні

* **Node.js**: версія 18.0.0 або вышэй
* **npm**: звычайна ўсталёўваецца разам з Node.js

### Усталяванне і наладжванне

1. **Клануйце рэпазіторый**

```bash
git clone https://github.com/dimartarmizi/map-to-poster.git
cd map-to-poster
```

2. **Усталюйце залежнасці**

```bash
npm install
```

3. **Запусціце сервер распрацоўкі**

```bash
npm run dev
```

Прыкладанне будзе даступнае па адрасе `http://localhost:5173`.

4. **Збярыце праект для production**

```bash
npm run build
```

Аптымізаваныя файлы будуць створаны ў каталогу `dist/`.

## 🐳 Разгортванне з дапамогай Docker

Праект гатовы да запуску ў лёгкавагавым Docker-кантэйнеры з выкарыстаннем шматэтапнай зборкі:

* **Этап зборкі**: выкарыстоўвае Node.js для ўсталявання залежнасцей і стварэння production-зборкі Vite.
* **Этап запуску**: выкарыстоўвае Nginx Alpine для абслугоўвання статычных файлаў з `dist/`.

### Зборка выявы

```bash
docker build -t map-to-poster .
```

### Запуск кантэйнера

```bash
docker run -d -p 8080:80 --name map-to-poster map-to-poster
```

Пасля гэтага адкрыйце `http://localhost:8080`.

### Абнаўленне разгортвання

Пасля атрымання новых змяненняў перазбярыце і перастварыце кантэйнер:

```bash
docker build -t map-to-poster .
docker rm -f map-to-poster
docker run -d -p 8080:80 --name map-to-poster map-to-poster
```

### Файлы Docker

* `Dockerfile` — production-вобраз са шматэтапнай зборкай
* `.dockerignore` — памяншае памер кантэксту зборкі
* `docker/nginx.conf` — канфігурацыя Nginx з SPA-fallback на `index.html`

## 📜 Тэхнічны агляд

1. **Рэактыўнае кіраванне станам**: выкарыстоўваецца store на аснове шаблону назіральніка ([src/core/state.js](src/core/state.js)), які сінхранізуе змены паміж інтэрфейсам, Leaflet і MapLibre. Усе карыстальніцкія налады захоўваюцца ў `localStorage`.
2. **Гібрыдны картаграфічны рухавік**: рэалізуе двухбаковую сінхранізацыю вобласці прагляду паміж Leaflet (растравыя тайлы) і MapLibre GL (вектарныя тэмы), забяспечваючы аднолькавае размяшчэнне элементаў незалежна ад актыўнага рэжыму рэндэрынгу.
3. **Сістэма перамяшчальных накладак**: выкарыстоўвае разлік межаў элементаў у рэальным часе для абмежавання пазіцый подпісаў і забяспечвае мінімальны бяспечны водступ 8 пікселяў ад краёў постара.
4. **Дынамічная інтэграцыя рэсурсаў**: кіруе ўласнымі GeoJSON-маршрутамі і некалькімі маркерамі з падтрымкай інтэрактыўнага перацягвання ў абодвух картаграфічных рухавіках.
5. **Слой паспарту**: рэалізуе віртуальны інтэрфейс «паспарту» з наладжвальным унутраным водступам і ўнутранымі рамкамі для стварэння галерэйнага выгляду.
6. **Высокадакладны працэс рэндэрынгу**: экспарт выкарыстоўвае шматэтапны працэс у [src/core/export.js](src/core/export.js) для стварэння высакаякасных здымкаў карты з дапамогай `html2canvas` і callback `onclone`.
